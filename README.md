# 🎵 P-Tunes – A Clean & Responsive Music Website

**P-Tunes** is a sleek and responsive music streaming interface designed to offer a clean and interactive user experience. Built with a frontend-focused approach, it provides a beautiful layout suitable for desktop and mobile users alike.

## 🚀 Features

- 🎧 Music Player with play/pause and seek functionality
- 📱 Fully responsive UI
- 🎨 Clean, modern design with interactive elements
- 💡 Intuitive layout with song title, playback bar, and controls
- 🔊 Real-time audio playback syncing with UI
- 🎯 Built using React.js and custom CSS (No UI libraries used)

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3
- **Audio Playback:** `<audio>` element
- **State Management:** React Hooks (`useState`, `useRef` ) Context API and other  React Advance concepts
- **Styling:** Custom CSS with media queries
